# Changelog

## [1.0.0] - 2026-07-06

### Added
- Config option to completely disable any Vinery wine (`config/winetoggle.json`)
- Disabled wines can't be crafted (fermentation barrel, apple press, or Create), are hidden from the creative menu / JEI / REI / recipe book, aren't sold by the winemaker villager or wandering trader, and can't be drunk
- Keeps the `wine_collector` advancement completable when a wine is disabled
- In-game config screen (Mod Menu on Fabric, mod list Config button on Forge)
